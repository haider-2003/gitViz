Command Reference
50+ git commands supported
Setup
git initInitialize new repository
git clone <url>Simulate cloning a repo
Staging & Committing
git add <file>Stage a file (use . for all)
git add -pInteractive staging (simulated)
git restore --staged <f>Unstage a file
git restore <file>Discard working changes
git commit -m "msg"Create a commit
git commit -am "msg"Stage all tracked + commit
git commit --amend -m "msg"Amend last commit message
git commit --amend --no-editAmend without changing message
Branches
git branchList all branches
git branch -vList with last commit info
git branch <name>Create a branch
git branch -m <old> <new>Rename a branch
git branch -d <name>Delete merged branch
git branch -D <name>Force delete branch
git branch --mergedBranches merged into HEAD
git branch --no-mergedBranches not yet merged
Checkout & Switch
git checkout <branch>Switch to branch
git checkout -b <name>Create and switch
git switch <branch>Switch branch (modern)
git switch -c <name>Create and switch (modern)
git switch -Switch to previous branch
git checkout <commit-id>Detach HEAD to commit
Merge & Rebase
git merge <branch>Merge (fast-forward or commit)
git merge --no-ff <branch>Always create merge commit
git merge --squash <branch>Squash into one staged change
git merge --abortAbort in-progress merge
git rebase <branch>Rebase current onto branch
git rebase -i HEAD~<n>Interactive rebase (simulated)
git cherry-pick <id>Copy commit onto current branch
git cherry-pick <a>..<b>Copy a range of commits
Stash
git stashStash working changes
git stash push -m "msg"Stash with a label
git stash listList all stashes
git stash popApply + drop top stash
git stash apply stash@{n}Apply without dropping
git stash drop / clearRemove stash(es)
git stash branch <name>Create branch from stash
git stash showShow stash contents
Reset & Revert
git reset HEAD~1Undo last commit (mixed)
git reset --soft HEAD~<n>Move HEAD back, keep staged
git reset --mixed HEAD~<n>Unstage changes (default)
git reset --hard HEAD~<n>Discard commits + changes
git revert <id>New commit undoing a commit
git revert HEADRevert last commit
Tags
git tag <name>Lightweight tag at HEAD
git tag -a <n> -m "msg"Annotated tag
git tag <name> <commit-id>Tag a specific commit
git tag -d <name>Delete a tag
Inspection
git logFull commit history
git log --oneline --graphCompact graph view
git statusWorking tree status
git diffShow unstaged changes
git show <id>Show commit details
git reflogFull HEAD movement history
git shortlogCommits grouped by author
git blame <file>Who changed what (simulated)
Remote (Simulated)
git remote add origin <url>Add a remote
git remote -vList remotes
git fetch / pull / pushRemote sync (simulated)
git push --forceForce push (simulated)
Config & Utility
git config user.name "name"Set author name
git config --listShow all config values
clearClear terminal output
resetWipe repo, start fresh
